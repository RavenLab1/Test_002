# RavenLab GLB Clicker Configurator

موقع ثابت يعمل على GitHub Pages ويستخدم ملفات GLB مباشرة.

## التشغيل المحلي

لا تفتح `index.html` مباشرة من الجهاز. شغّل سيرفر محلي:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## مكان المجسمات

كل المجسمات موجودة داخل:

```text
assets/models/
```

## التحكم من المشهد

- اضغط على الكاب داخل العرض لتحديده.
- استخدم Shift أو Ctrl لتحديد أكثر من كاب.
- بعدها غيّر شكل الكاب أو لونه من لوحة التحكم.

## ملاحظات

- خيارات القاعدة 1 إلى 9 ظاهرة.
- ملفات Square تظهر فقط للأعداد التي لديها مجسم Square.
- ملف `base_10.glb` موجود داخل assets/models لكنه مخفي من الواجهة لأن النسخة الحالية مطلوبة 1-9.
