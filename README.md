# RavenLab GLB Clicker Configurator

نسخة مبسطة للجوال أولًا.

## التحديثات الجديدة

- جعل تجربة الجوال أبسط: معاينة ثابتة في الأعلى، وخيارات كبيرة وواضحة أسفلها.
- إضافة شرح سريع داخل صفحة التصميم: اختر عدد الأزرار، اختر اللون، اضغط على الكاب، ثم أكمل الطلب.
- تقليل النصوص والأزرار الصغيرة حتى تكون التجربة أوضح للعملاء.
- إضافة ملاحظة داخل تفاصيل الطلب:
  `السعر النهائي يتم تأكيده من RavenLab بعد مراجعة الطلب.`
- الفاتورة نص عادي جاهز للإرسال، وليست JSON.
- إضافة علامة RavenLab المائية داخل المشهد.
- إضافة حماية دومين مبدئية تمنع تشغيل الموقع على دومين غير مصرح.

## حماية الموقع

الحماية موجودة في:

```text
assets/js/app.js
```

ابحث عن:

```js
security: {
```

أضف دومينك الرسمي داخل `allowedHostnames`.

ملاحظة مهمة: لأن الموقع ثابت ويعمل على GitHub Pages، لا توجد حماية كاملة من نسخ الملفات. الحماية الحالية تمنع الاستخدام السهل على دومين آخر، وتضيف علامة RavenLab، لكنها لا تغني عن استضافة خاصة أو Backend عند الحاجة لحماية أقوى.

## تشغيل محلي

لا تفتح `index.html` مباشرة. شغل سيرفر محلي:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## رفع GitHub Pages

ارفع محتويات هذا المجلد كما هي إلى المستودع:

```text
index.html
assets/
README.md
.nojekyll
```

ثم فعّل Pages من:

```text
Settings -> Pages -> Deploy from branch -> main -> / root
```
