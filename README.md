# RavenLab GLB Clicker Configurator

نسخة محدثة مناسبة للجوال أولًا.

## التحديثات

- تصميم أخف وأسهل للجوال.
- شرح خطوات التصميم في بداية الصفحة.
- المشهد ثلاثي الأبعاد في الأعلى على الجوال.
- أدوات التعديل أسفل المشهد.
- زر نهائي باسم **إكمال الطلب**.
- نافذة تعرض تفاصيل الطلب بصيغة جاهزة للنسخ والإرسال.
- دعم زر المشاركة على الجوال عند توفره.
- كابات الحروف تستخدم ملفات منفصلة: `keycap_a.glb`, `keycap_g.glb` وهكذا حسب الحرف المختار.
- اختيار الكاب من المشهد بالنقرة فقط، والسحب صار مخصصًا للدوران حتى لا يتغير التحديد بالغلط على الجوال.

## تشغيل محلي

لا تفتح `index.html` مباشرة. شغل سيرفر محلي:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## رفع GitHub Pages

ارفع محتويات هذا المجلد كما هي إلى المستودع:

```text
index.html
assets/
README.md
.nojekyll
```

ثم فعّل Pages من:

```text
Settings -> Pages -> Deploy from branch -> main -> / root
```

- الفاتورة الظاهرة للعميل نص عادي وليست JSON.
